Sections

Type, number of questions, choices. True/False always has 2 choices. In Matching, each item picks one letter from a list printed on your exam paper. Multiple select allows several marks.

When printing, choose A4, margins none, and scale 100% (actual size). Do not use “fit to page”, because it changes the bubble positions the scanner expects.
