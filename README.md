# Bubble Grader

Static web app (no build step). Files: index.html, sheet-generator.html, scanner.html, manifest.webmanifest, sw.js, icons.

## Host on GitHub Pages
1. Create a new public repository on GitHub.
2. Upload every file from this folder to the repository root (not inside a subfolder).
3. Settings > Pages > Source: "Deploy from a branch", branch main, folder / (root). Save.
4. After a minute, open https://YOUR-USERNAME.github.io/REPO-NAME/ in Chrome on your phone.
5. Chrome menu > Install app.

Data (keys, results) is stored in the browser on that device only. Print sheets and scan on the same phone origin, and export CSV regularly as a backup.
